## HIGH (Hard Gate)

**1. Rendered em dashes throughout the copy — R-02**
The raw text never contains the literal `—` character, but `&mdash;` is used dozens of times (guide section, problem section, solutions section, form section, popup) and renders as the exact same glyph the rule bans. Since R-02 governs what a reader sees, not the byte encoding, this reads as a straightforward violation once rendered.
*Location:* pervasive — e.g. lines 580, 586, 590, 598, 606, 615, 618, 624, 627, 633, 636, 775, 787, 799, 837, 1042, 1046, 1143, 1175, 1200, 1204, 1298, 1396, 1523, 1719.

**2. Unsourced statistic: "94% of cohorts still running at 12 months" — R-17**
Presented as a bare fact with no citation, unlike the 60%/3x stat which does have a linked source elsewhere on the page.
*Location:* line 1202, Team Institute accordion description.

**3. Unsourced dollar figures in the comparison table — R-17**
"$400K burning annually" / "Full $1M investment realized" are specific, fact-styled numbers with no source and no "for example" framing to mark them as illustrative.
*Location:* lines 775, 778, `.compare-row` "Capacity" row.

**4. Placeholder logo disguised as a real client — R-23 / R-38**
One trust-bar entry links to `https://www.example.com` with `alt="LOGO"` and a generic filename, sitting among ~40 real, named institution logos with real hrefs. It reads as a real accredited client but is a leftover placeholder that never got swapped.
*Location:* lines 265–267 and its duplicate at 407–409 (the logo track is doubled for the marquee loop).

**5. Low-contrast "faint" text on navy backgrounds — R-25**
A recurring pattern of white text at 20–40% opacity on the `#08152a`/`#0d1e35` navy backgrounds, used for labels, stat captions, and body copy at small sizes (10–14px). Estimated contrast for several of these lands around 3–4:1, below the 4.5:1 floor for normal-size text. This can't be measured exactly without rendering, so treat this as "likely fails, verify with a contrast checker before shipping," not a certain fail.
*Representative locations:* `.paradox-source` (rgba(255,255,255,.28), line ~708), `.pstat-l` (rgba(255,255,255,.4), line 706), `.compare-head-cell` (rgba(255,255,255,.35), line 695), `.hpg-primary-fmt` (rgba(255,255,255,.28), line 913), `.hpg-desc` (rgba(255,255,255,.38), line 951), `.home-notready p` (rgba(255,255,255,.4), line 1281).

## MEDIUM (Purpose-Gate + Hard-Gate-adjacent)

**6. "30+ years of convergent global research" — no citation — R-17**
A specific, quantified research claim ("Fortune 500 companies, hospitals, government, six continents") with no link, unlike the sibling 60%/3x stat which does cite a source.
*Location:* line 586, guide section.

**7. "1,050 leadership teams" repeated without its citation — R-17 consistency**
The number is sourced once (line 834, linked to `higherperformancegroup.com/research`) but repeated earlier in the guide section's stat row with no link back to that source.
*Location:* line 595 vs. 834.

**8. Popup modal has no focus trap — R-32**
Escape closes it and it's keyboard-reachable, satisfying the rule's letter, but nothing stops Tab from moving focus out of the open dialog into the hidden page behind it — the modal pattern's usual expectation.
*Location:* lines 1740–1763, `#hpg-pop-overlay` script.

**9. Arrow-on-every-CTA — R-08**
Every single link/button in the file ends in `→` (hero, primary CTA, all four accordion CTAs, coffee CTA, form submit, popup CTA, both "how it works" links) — nine instances, uniform, no variation. This reads as a consistent brand motif rather than random decoration, which the Liveliness Toolkit actually favors, but it's applied literally everywhere with no exception, which is what R-08 flags as a default habit. Worth a one-line decision: keep it as a deliberate "forward motion" motif (fine, write that down) or vary it for hierarchy.
*Location:* pervasive.

**10. Generic CTA copy: "Get Started →" — R-15**
This is the literal forbidden example in R-15. Every other CTA on the page is specific ("Book The Proof," "Reserve a Date," "Explore the Institute") — this one stands out as the generic default.
*Location:* line 1556 (and repeated at 1647 in the JS reset), contact form submit button.

**11. "How It Works" — 3 numbered circle steps — R-05**
Matches the named anti-pattern closely: round icon-in-circle + numeral + short blurb, three steps. Content is real and specific to HPG's actual process (not filler), and the dotted connector line adds some distinction, but the core visual formula is the textbook version the rule calls out. Worth a deliberate variation, or an explicit note that this shape was chosen on purpose.
*Location:* lines 1355–1399.

**12. Two font pairings on one page — R-06 consistency**
Playfair Display + DM Sans for the main page, but Cormorant Garamond + Outfit for the Burnout Force popup — explicitly justified in the code comment as matching the Burnout Force sub-brand's own site. Reasonable, but worth confirming with the client that visitors reading two different typographic voices on one page is intentional cross-brand signaling and not visual inconsistency.
*Location:* lines 1661–1671 (comment), 1672 (font import).

**13. Red accent color scoped to the popup only — R-29**
The page's palette is navy/gold/cream (2 core + 1 accent). The popup introduces red (`#e03a2b`/`#b83228`) not used anywhere else, again justified by sub-brand matching. Same call as #12: confirm the deliberate clash reads as intentional, not accidental.
*Location:* lines 1680–1689.
